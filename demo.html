Basic Patterns

Simple Digits

Generate 5-digit number

\d{5}
-

Word Characters

Random alphanumeric + underscore

\w{8}
-

Character Range

Lowercase letters only

-

Mixed Case

Upper and lowercase letters

[A-Za-z]{12}

Advanced Features v4.0.0

Named Backreferences

Repeat captured named group

(?<word>\w{3})-\k<word>
-

Numeric Backreferences

Repeat captured group by number

(\d{3})-\1-\1
-

Unicode: Greek Letters

Greek alphabet characters

\p{Greek}{8}
-

Unicode: Cyrillic

Russian/Cyrillic characters

\p{Cyrillic}{10}
-

Conditional Pattern

If-then-else logic in regex

(?<test>x)?(?(test)y|z)
-

Lookahead Assertion

Pattern with zero-width lookahead

(?<id>\d{3})(?=-)\k<id>
-

Multiple Named Groups

Multiple captured groups

(?<user>\w+)@(?<domain>\w+)\.\k<domain>
-

All Features Combined

Unicode + Named + Lookahead + Conditional

(?<word>\p{L}{3})(?=-)\k<word>(?(word)!|)
-

Quantifiers & Alternation

Greedy Quantifier (+)

One or more (greedy)

\d+
-

Lazy Quantifier (+?)

One or more (lazy/non-greedy)

\d+?
-

Alternation

Choose from multiple options

(red|green|blue|yellow|orange)
-

Complex Alternation

Multiple patterns with alternation

-

Range Quantifier

Between min and max occurrences

[a-z]{5,15}
-

Optional Pattern (?)

Zero or one occurrence

https?://[a-z]+\.com
